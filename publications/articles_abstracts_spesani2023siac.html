Abstract

Environmental degradation caused by fossil-fuel use has created a need for sustainable alternative fuels (WAGSTROM; HILL, 2020). Biofuels offer a promising option because their combustion generates fewer pollutants and greenhouse gases. Computational tools for predicting and optimizing the behavior of these flows are therefore essential to their future viability. This project aims to develop a finite element fluid-flow simulator for biofuel-related flow through a filter modeled as a porous medium. A detailed study of the problem geometry was conducted, resulting in a complex geometry discretized with an unstructured finite element mesh (RABELLO, 2022, p. 3). The flow was analyzed using the streamfunction-vorticity formulation (CARNEVALE, L.H; ANJOS, G.H; MANGIAVACHI, 2018) and Darcy's equation for porous media. Python was the main tool used to implement the numerical code through rapid prototyping in an environment suited to developing advanced procedures.
